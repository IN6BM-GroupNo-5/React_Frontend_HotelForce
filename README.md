# 🏨🌐 React_Frontend_HotelForce

### 🪪 Por: IN6BM 2025 | Grupo No.5  
### Para: Fundación KINAL

📍 El objetivo de este proyecto (Parte de Frontend) es desarrollar una aplicación web para la **gestión hotelera**, implementando eficazmente el stack MERN (MongoDB, Express, React, Node.js) para crear un sistema funcional, escalable y moderno.

Esta plataforma permite a los usuarios realizar búsquedas de hoteles, reservar habitaciones, consultar eventos, y acceder a su historial. También ofrece funcionalidades especializadas para **administradores de hoteles** y **administradores de la plataforma**, incluyendo gestión de reservas, generación de reportes, creación de eventos y control general del sistema.

## 🧑‍💻 Tipos de usuarios:
* Clientes registrados
* Administradores de hotel
* Administradores de plataforma

## 🧩 Funcionalidades principales:
* Registro y login de usuarios
* Búsqueda y reserva de habitaciones disponibles
* Visualización de eventos en los hoteles
* Gestión de usuarios y hoteles (admin plataforma)
* Gestión de reservas, eventos y facturas (admin hotel)
* Estadísticas gráficas y reportes generales
