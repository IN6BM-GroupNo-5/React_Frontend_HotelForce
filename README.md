📍 El objetivo de este proyecto (Parte de Frontend) es desarrollar una **aplicación web de gestión hotelera** como parte de una plataforma completa construida con el stack MERN (MongoDB, Express, React, Node.js). Esta interfaz permite a distintos tipos de usuarios interactuar con el sistema de forma eficiente y moderna.

👥 Usuarios del sistema:
- **Clientes:** pueden registrarse, buscar hoteles, reservar habitaciones, y consultar eventos.
- **Administradores de hotel:** pueden ver y gestionar reservas, crear eventos y generar facturas.
- **Administradores de plataforma:** tienen control general sobre hoteles, usuarios y reportes.

🔍 Entre sus funcionalidades se incluyen:
- Autenticación de usuarios (registro, login).
- Visualización y reserva de habitaciones.
- Gestión de eventos por parte del hotel.
- Paneles administrativos diferenciados por rol.
- Generación de reportes y visualización de estadísticas.

🚀 Esta aplicación está diseñada para ser:
- Intuitiva, rápida y responsive.
- Escalable y segura, con validación en frontend y backend.
- Dividida en componentes reutilizables, usando React y React-Bootstrap.
